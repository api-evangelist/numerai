# Numerai

> Numerai is a hedge fund that runs a crowdsourced data-science tournament: participants download
> obfuscated financial datasets, train machine-learning models, and submit predictions each round,
> staking the NMR cryptocurrency on their models to earn payouts. Programmatic access is a single
> GraphQL API at api-tournament.numer.ai covering Numerai Classic, Numerai Signals, and Crypto Signals.

## API
- [GraphQL API](https://api-tournament.numer.ai): Single POST endpoint (Elixir/Absinthe), introspection enabled. Auth via API token pair (x-public-id / x-secret-key) with per-token scopes.
- [Documentation](https://docs.numer.ai): Tournament rules, data, submissions, staking, and automation guides.

## SDKs & CLI
- [numerapi (Python)](https://pypi.org/project/numerapi/): Docs-recommended client + CLI for datasets and submissions.
- [numerai-cli (Python)](https://pypi.org/project/numerai-cli/): Official CLI to deploy cloud Prediction Nodes.
- [numerai-tools (Python)](https://pypi.org/project/numerai-tools/): Official scoring/interaction tools.
